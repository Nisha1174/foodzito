# 🍔 FoodZito - Full Stack Food Delivery App (MERN)

FoodZito is a full-stack food delivery web application built using the MERN stack. It allows users to browse restaurants, order food, track deliveries, and manage their profile.

---

## 🚀 Features

### 👤 User Features
- User Signup & Login
- Browse restaurants & menus
- Add items to cart 🛒
- Place orders
- Order tracking 📦
- View order history

### 🏪 Restaurant Features
- Restaurant listing
- Menu management
- Reviews & ratings ⭐

### 📊 Dashboard Features
- User Dashboard
- Owner Dashboard

### 💡 Additional Features
- Payment Simulation 💳
- Location Picker 🗺️
- Map Integration
- Email functionality (Mail utility)

---

## 🛠️ Tech Stack

### Frontend:
- React.js
- Vite
- Tailwind CSS
- Redux Toolkit

### Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication
